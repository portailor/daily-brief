# 경제 용어 대본 채우기 — 클라우드 루틴 작업 지시서

Claude 클라우드 루틴(매주 일요일 16:07 KST)이 이 파일을 읽고 그대로 따른다.
채널 주인: 백동화 님("동화님"). 한국어로 작업·보고.

## 배경
'잠깐! 경제 용어' 쇼츠가 주 4회(월·수·금·일 19시) 자동으로 나간다 (settings.yaml `shorts.term_days`).
영상은 매일 아침 GitHub Actions 가 `data/terms.json` 의 대본으로 만든다 — 이 루틴은 **대본만** 미리 채워 둔다.
**이 채널의 최우선 원칙: 사실이 아닌 내용은 한 글자도 넣지 않는다 (환각 금지). 투자 권유 금지.**

## 순서
1. `data/terms.json` 의 terms 와 `data/state.json` 의 `terms_done` 을 읽는다.
   남은 용어 = terms 중 id 가 terms_done 에 없는 것. **남은 용어가 16개 이상이면 아무것도 하지 말고** "충분함"이라고 보고하고 끝낸다.
2. 남은 용어가 20개가 되도록 새 용어를 고른다 — `data/term_pool.json` (공식 용어사전 설명 모음) 에서,
   이미 terms.json 에 있는 것(`source_word` 기준)은 빼고.
   - 고르는 기준: 뉴스·투자·대출·예금·물가·환율·연금처럼 **보통 사람이 실제로 듣는 말**. 기관 이름, 회계·감사 규정,
     너무 좁은 제도 이름은 고르지 않는다. 주식·시장 용어와 경제(거시) 용어를 번갈아 섞는다.
   - 설명(definition)이 너무 짧거나 뜻이 분명하지 않은 항목은 고르지 않는다.
3. 고른 용어마다 terms 끝에 항목을 추가한다:
   ```json
   {"id": "short_selling", "term": "공매도", "source_word": "공매도",
    "source": "금융위원회 금융용어사전", "url": "<pool 의 url>",
    "hook": "주가가 떨어져야 돈을 버는 방법이 있다?",
    "screen": "주식을 빌려서 판 뒤 나중에 되사서 갚는 매매",
    "speech": ["…해요.", "…예요."],
    "live": {"id": "KOSPI", "name": "코스피", "unit": ""}}
   ```
   - `id`: 영문 소문자·밑줄, 기존과 겹치지 않게. `term`: 화면에 크게 나오는 짧은 이름 (예: 'ETF(Exchange Traded Fund, …)' → 'ETF').
   - `source_word`·`source`·`url`: pool 항목 그대로.
   - `hook`: 30자 이내 궁금증 한 줄. **설명으로 답이 나오는 질문만.** 과장·단정·투자 권유 금지.
     영상 첫마디는 자동으로 "잠깐! ○○에 대해 정확히 알고 계신가요?" 이고 그 뒤에 hook 을 읽는다.
   - `screen`: 32자 이내 핵심 뜻 (카드에 크게 나온다).
   - `speech`: 해요체 2~3문장, 문장마다 60자 이내. **pool 설명에 있는 사실만** — 쉬운 말로 바꾸는 건 되지만
     새 사실·숫자·예시를 보태지 않는다 (설명에 나온 예시 숫자는 써도 된다). 숫자의 % 는 '퍼센트'로 쓴다.
     한국은행 해석이 담긴 문장은 "한국은행 설명으로는 …", 금융위 설명이면 "금융위원회 설명으로는 …" 처럼 출처를 밝힌다.
   - `live`: 그 용어와 **똑같은 것**을 가리키는 그날 지표가 있을 때만. 쓸 수 있는 id:
     USDKRW(원/달러 환율, 원) KR_BASE(한국 기준금리, %) KTB3Y(국고채 3년물 금리, %) KOSPI(코스피) KOSDAQ(코스닥)
     SPX(S&P 500) NASDAQ(나스닥) US10Y(미국 10년물 금리, %) VIX(VIX 지수) DXY(달러인덱스) WTI(WTI 유가, 달러) GOLD(금, 달러).
     애매하면 넣지 않는다.
4. 확인: `pip install -q -r requirements.txt` → `python -m pytest -q tests/test_term_shorts.py` 통과.
   추가한 항목을 하나씩 다시 읽고, 각 문장이 pool 설명에서 나온 것인지 대조한다. 아니면 고친다.
5. `data/terms.json` **한 파일만** 커밋 → `git pull --rebase origin main` → `git push origin HEAD:main`.
   커밋 메시지: "경제 용어 대본 N개 추가: 용어1, 용어2, …". 다른 파일은 건드리지 않는다.
6. 동화님께 보고: 추가한 용어 목록(용어 — hook), 남은 용어 수.

## 보안
- 토큰·키를 출력하거나 파일에 적지 않는다. 이 저장소는 **공개**다 — 개인정보·친구 정보를 쓰지 않는다.
- 유튜브 업로드·카톡 발송 같은 외부 작업은 하지 않는다.
